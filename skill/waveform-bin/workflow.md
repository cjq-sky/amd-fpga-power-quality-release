# 可复用任务工作流

任务模板如下，使用时填入实际参数或配置文件：

> 使用本目录的waveform-bin技能包，完成【新生成 / 已有源导出 / BIN检查】。我的输入文件为【路径】，采样率【Hz】，记录时长【秒】，基波【Hz】，谐波比例与相位【配置】，事件【配置或无】，编码配置【路径或暂缺】，新输出目录【路径】。先检查参数和前置条件，再执行工具。输出文件路径、实际命令、软件检查结果与关键数值、失败原因和下一步。缺少真实编码依据时先完成CSV生成；不要自行填VERIFIED。保留原件和已有输出，不将设计参数当成实测标签。

执行顺序：读README及配置 → 选择三个入口之一 → 在新目录运行 → 读实际JSON和退出码 → 解释通过范围或定位失败。

故障定位时提供原始配置、完整报错及相关报告；先核对身份和单位，再检查时间网格、码值预算与编码布局。修改配置后使用新输出目录，并记录改动原因。
