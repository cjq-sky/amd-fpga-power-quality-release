# 经验来源、触发条件与排查

| 观察或失败来源 | 触发条件 | 排查与处理 | 验证边界 |
|---|---|---|---|
| 已有事件说明记录了整段重复率与基波混淆风险 | 1秒、50Hz基波记录被按50Hz整段播放 | 计算1/duration_s，区分记录重复率与内部周期；现场核对仪器设置 | 数字时长可核对，实机播放需测量 |
| v0.2.1回归中的暂升码值溢出用例 | 暂升或谐波叠加超出profile预算 | 查看极值与余量，显式调整幅值或映射，保留失败记录 | 不削顶；新映射需现场依据 |
| 回归中的源篡改与BIN篡改用例 | 文件可读但与原源不一致 | 核对哈希，使用compare-source逐点检查，回到原件重新导出 | 哈希证明文件身份，不证明实验工况 |
| 回归中的事件网格与重叠用例 | 时间不能映射成整数采样索引或事件相交 | 以采样间隔配置时间，检查事件区间和斜坡 | 不静默舍入 |
| 旧CSV精度与v0.2.1重导出策略 | 按设计浮点值重算与保存CSV产生差异 | 按实际保存的源值编码；新CSV保留17位有效数字 | 新版直接生成与重导出一致已由测试覆盖 |
| 项目波形变体与谱系观察 | 将幅相变化当独立测试来源 | 明确保留lineage_group_id，后续另做数据资格审核 | 本工具不放行训练或测试集 |
