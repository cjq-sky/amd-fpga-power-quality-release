# 可复用审核工作流

可复用任务模板：

> 使用capture-audit技能包审核【材料路径】，结果写入【新目录】。先盘点源文件、Run、Raw、Feature、参考及已有声明；分别核对文件完整性和实验身份。适配现有格式，保留原件。列出选定Run、被替代旧尝试、对应参考、证据路径/哈希和未确认项。运行兼容格式检查器并解释实际结果；不要将结构完整写成标签或训练通过。先复用已有声明与重采，不自动提出整批重采。

1. 盘点：按inventory.csv逐文件登记，SHA256从实际内容计算；清单自身另存哈希，区分“清单声明值”和“实际计算值”。
2. 身份：源清单、实际加载源记录、Run、参考分别交叉核对。逐帧关联与工况级关联分开，不从相同文件名推出同一实验。
3. 选定：按selection.csv指定替换链、理由与依据；每个工况明确唯一选定关系。一个参考覆盖多个Run时须说明稳定工况依据，不能默认共时钟。
4. 隔离：保留旧文件与旧哈希，标记SUPERSEDED或QUARANTINED并写原因；检查后续清单没有误用旧尝试。
5. 人工确认：引用已有声明及其覆盖Run。签名/操作者身份、日期和原话如实记录；不记得的留null。声明不能替代文件身份核对。
6. 交付：输出自动报告、映射表、隔离表、确认索引和PENDING列表；报告审核范围及仍未评估的数值/标签问题。
