# 可复用技能包

Python3.10+。各包可独立阅读和使用，命令从对应技能目录执行；输出选择新路径，不覆盖输入。

|技能|功能版本|内容|
|---|---|---|
|[waveform-bin](waveform-bin/README.md)|1.0，工具0.2.1|波形候选生成、BIN导出、回读及源点一致性|
|[capture-audit](capture-audit/README.md)|1.0|采集材料完整性、源/Run/参考对应、重采追溯|
|[model-handoff](model-handoff/README.md)|1.1|模型合同、黄金回放比对及EV26保存结果成对计分|

每项含README、SKILL.md、操作流程、脚本、示例与经验来源。工作流中的任务模板可直接复用。验证JSON为既有结果的技术摘要；文件检查不重新执行示例、模型或测试。

## 版本与系统状态

现用125MHz整机已经完成板端模型、事件及HDMI/PC显示接入。技能包中的早期板端记录分别对应正弦接入和四工况验证，不代表当前整机仍停留在这些阶段。v1.1另外包含EV26成对评分结果，详见[版本范围](model-handoff/references/version_scope.md)。

技能包只声明各工具的能力和已记录验证范围，不替代整机验收。模板/人工夹具不当作真实采集；TRAIN黄金用于数值一致性，EV26保存案例已用于选模，不当作独立泛化测试。

## 文件与来源

本目录sha256.json覆盖当前布局；嵌套清单同步更新。文件名及示例目录已规范化，原模型权重、deployment_manifest、golden及EV26数值文件保持原字节。根SHA256SUMS核对工程文件完整性；原模型和数值结果按其版本解释。

从工程根目录执行python -B build/scripts/check_skill.py只检查结构、引用、语法和文件身份，不运行技能内容。技能所需示例与自检放在各自目录，不参与板端应用启动。
