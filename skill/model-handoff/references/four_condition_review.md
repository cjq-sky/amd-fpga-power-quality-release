# 四工况模型调用记录摘要

记录日期2026-11-02，承接早期正弦接入；此页保留当时结果，不重新安排采集。后续EV26与现用系统状态见[版本范围](version_scope.md)。

正常正弦、H3主导、H5主导和MIXED各执行LR/RF，合计8轮；每轮2次隔离和32次有效，合计272次保存处理、256有效帧。其中64有效帧沿用前次正弦记录，192有效帧为随后三类记录，不重复计作新增采集。4个启动隔离输入被Reader拒绝，模型预测为空。

|工况|LR有效输出|RF有效输出|当时Event|
|---|---|---|---|
|50Hz正弦|32 CLEAN|32 CLEAN|NORMAL|
|H3主导已知源|32 H3_DOMINANT|32 H3_DOMINANT|SAG|
|H5主导已知源|32 H5_DOMINANT|32 H5_DOMINANT|SAG|
|混合谐波已知源|32 MIXED|32 MIXED|SAG|

保存输入与冻结模型数值一致，概率差不超过1e-6。Raw/Feature的UNMATCHED原样保留。已知源曾用于TRAIN，此结果支持真实调用覆盖，不等于独立准确率100%。当时Event=SAG按原基线及工况记录，不为显示NORMAL更改幅度或门限。

当时LR调用中位约0.569～0.578ms，RF约5.564～6.361ms；两算法分时运行，不能以整轮耗时相减推算净开销。原后续算法比较已由EV26提供补充，现用125MHz系统也已接入模型和显示。故本页不保留“等待选模、继续开发HDMI”等过期任务。
