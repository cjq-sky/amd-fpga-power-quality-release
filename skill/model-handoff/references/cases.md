# 经验来源与边界

- 依赖不兼容：训练环境Python3.12、sklearn/joblib与板端Python3.10.4 ARMv7不一致，板端无sklearn/joblib。实际采用JSON与标准库部署，保留原模型身份；LR保留分步float32舍入、RF保留树阈值分支。来源为实例内deployment_guide.md及export_verification.json。规则：格式转换后先黄金比对，不能手工改权重或默认兼容。
- 资格与用途：原训练批次78个合格Run、2496训练帧，69/75共64帧专项隔离；CLEAN仅一个来源谱系。规则：排除理由与谱系不丢失，训练回代和TRAIN黄金不当作独立测试。来源为原训练交付包；本包只提供组织模板，不移植本队物理门限。
- 输入合同：六维前五项为百分数、Crest为比值；LR已含缩放。规则：输入转换只在约定层执行一次，标签ID与概率顺序显式核对。
- 真实拒绝：四工况8轮256有效帧之外，4个启动隔离输入被Reader拒绝，模型保持空预测。原MODEL_NOT_READY及UNMATCHED按原语义保留。规则：原Adapter状态、输入资格与新增模型结果分开；文件同时存在不能升级运行时关联。
- 观察域：CLEAN真实正弦运行H1高于训练观察范围，仍可作为链路运行证据，不能自动成为正式带标签测试。规则：工程成功与数据资格分别记录。
- 性能：包装调用、整轮处理和ADC至UI时延不同；离线验证进程内存不等于实时服务内存。四工况属于已知训练源接入覆盖，不是独立准确率。

早期板端复核摘要见initial_board_review.md与four_condition_review.md，来源哈希见provenance.json；这些记录只代表对应日期的观察范围。v1.1已包含EV26的12工况保存结果评估，现用125MHz系统的模型和HDMI接入也已完成。详情见[版本范围](version_scope.md)；技能包本身不替代整机指标验收。
