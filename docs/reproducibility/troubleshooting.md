# 125 MHz运行排障

先保存原错误、当前boot标识、文件身份及已有运行记录，不自动重载、reset或重复启动。运行结果留在results/，不提交凭据或个人资料。

|现象|处理|
|---|---|
|--check文件/合同失败|按报错定位缺失或变更，核对SHA256SUMS、模块身份清单与对应发布版本；不直接改预期SHA凑通过|
|电脑无法执行--precheck/默认入口|这是板端Linux入口；电脑仅运行--check、--plan|
|架构、内核或原生指纹失败|核对合格镜像与Python环境；同名镜像不证明二进制一致，不pip升级或改指纹|
|sudo找不到PYNQ|确认sudo实际解释器是否为已验证环境，使用该环境绝对路径；不安装另一套库代替|
|字体缺失|核对系统DroidSansFallbackFull.ttf合法安装；新程序不使用旧PQ_UI_FONT入口|
|模型缺失/哈希不符|核对固定服务路径四文件；已有未知文件先核实，不覆盖、不改白名单|
|网络/8765初筛失败|核对192.168.2.99实际配置和已有服务；不要重复启动或自动改网络|
|锁非空、被占或本boot已有启动记录|停止新启动；核实旧owner，按原流程关机并完整断电；不删锁、不杀进程冒充安全停止|
|IDENTITY_CHECK_PASS之前失败|保持失败原状，查配套固件、PS时钟及MMIO身份，不混用旧Lab07/unified_2|
|未出现STAGE4_READY|保留原错误和引用，按原程序状态处置；DMA可能活动时不freebuffer或反复reset|
|画面不刷新|确认已在ui4>启用auto on；auto off只暂停提交，不证明DMA停止|
|触摸无响应|核对USB连接及原输入设备识别、touch on状态；不要再开一个视频程序|
|PC打不开|核对同网段/路由、板端地址与8765、原程序状态；PC与HDMI共用快照，不另开Reader|
|Raw/Feature为UNMATCHED|如实保留独立帧身份，不借邻帧补配，不把它自动解释为整机兼容故障|
|模型无资格/未标定/unknown|按原输入合同、状态和原始原因处理，不伪造分类或物理标定|

正常结束：保留owner进程及缓冲引用，在另一终端poweroff，然后完整断电。详细步骤见[运行指南](run_guide.md)。旧快照控制台的load/snapshot/hdmi/page不是当前操作步骤。


七寸屏闪烁或供电不足时，先核对CTOUCH数据线与供电方式，必要的独立POWER供电按屏幕说明书5V/2A能力准备；不套用树莓派config.txt或Windows注册表修复。面板1024×600不等于输入视频格式，不据此改现用1280×720程序。

完整数字接线图已转为hardware_setup.md和ad7606_wiring.csv；BUSY、FRSTDATA、共用CONVST、共地及Pmod复用有明确位置。AD7606供电/VDRIVE与固定配置已在硬件说明列明：独立5V、J1为3V3、J2为±10V、OS=000、SER=0、STBY=1；模块5V供电与3.3V数字接口分别处理。
