## 控制、状态与共地

|信号|AD7606 J5|PYNQ RPi物理针脚|FPGA管脚|方向/端口|
|---|---|---:|---|---|
|BUSY|19|18|Y7|ADC→PYNQ，ad_busy|
|FRSTDATA / FRD|20|22|F20|ADC→PYNQ，ad_frstdata|
|CONVST_A|26|37|W9|PYNQ→ADC，ad_convst|
|CONVST_B|23|37|W9|与CONVST_A共接同一ad_convst|
|RESET|24|7|Y18|PYNQ→ADC，ad_reset|
|CS_N|22|29|Y19|PYNQ→ADC，ad_cs_n|
|RD / SCLK|21|31|U18|PYNQ→ADC，ad_rd_n；此设计使用并行读|
|GND|32|6|—|公共地|

CONVST_A/B必须同时接物理37，保证本设计采用的同步转换关系。RESET、CS_N、RD_N涉及Pmod A复用资源，保留现用连接，不接入争用设备。数字管脚约束LVCMOS33，不由此推断ADC模拟供电也为3.3V。

## 模拟输入、供电与跳帽

既有模拟输入对应V1/CH1为模块J3-9、V2/CH2为J3-8，参考AGND；Raw低16位CH1、高16位CH2。通道是逻辑编号，不能自动称为市电电压/电流传感器输入。

### 本工程电源与固定配置

本地模块图纸、既有接线说明及后续记录已给出以下复现设置。模块PCB标识AD7606 ADC V3.1，芯片AD7606BSTZ；模块原理图标注V3.1、2020-03-30。资料包目录版本不作为PCB版本替代。

|项目|本工程设置|位置与连接|
|---|---|---|
|模块主电源|独立稳压5V直流供电|J4-2接+5V，J4-1接AGND|
|电源引出|J5-31为同一+5V电源网，J5-32为AGND|采用J4供电时不再另向J5-31并接第二路电源；J5-32与PYNQ物理6共地|
|VDRIVE / 接口电平|3.3V|J1短接2–3，选择3V3档；板内3.3VD经J1接到VDR|
|模拟量程|±10V|J2短接1–2，选择±10V档，RANGE为高|
|过采样|OS[2:0]=000，不启用过采样|OS0为J5-29、OS1为J5-30、OS2为J5-27，固定为低|
|接口模式|16位并行|SER / PAR/SER/BYTE SEL为J5-28，固定为低|
|运行/待机|STBY为高，正常工作|J5-25，按模块图经PR7上拉至VDR|
|参考源|使用芯片内部参考|REF SELECT经R1上拉至VDR，内部参考标称2.5V|

原理图通过PR2的4.7kΩ电阻将OS0/OS1/OS2及SER下拉，通过PR7的4.7kΩ电阻将STBY上拉；这些是模块固定配置，不占用新增PYNQ GPIO。DB14和DB15仍是数据总线，不能当作8位模式的固定控制脚使用。

既有实物记录已确认J1位于3V3、J2位于±10V，后续记录写有VDRIVE约3.3V。本表给出固定接线和模式；实际部署仍须核对电源、电平与跳帽。AD7606芯片手册Table 8及Table 9分别定义16位并行选择和OS=000无过采样；VDRIVE决定数字接口电平，模块5V电源不接入普通FPGA GPIO。

ADC主电源需在现用程序加载固件并发出启动RESET之前稳定。保留现有断电接线、独立5V供电、共地、3V3接口和±10V量程设置；不更改既有控制器、采样周期或量程换算。高压市电不能直接接ADC。


已有受控参考为正弦50Hz、1Vpp、Offset0、High-Z、ON；曾有CH2=600mVpp的相对工况。发生器OFF不等于已知0V或零ADC code。以实际接线和示波器观察确认输入，不通过清零/改基准掩盖偏置。

## 七寸HDMI触摸屏

现用屏幕尺寸为7英寸。所附系列说明书为2020年3月版，七寸规格表标称面板1024×600；HDMI、USB触摸/供电及独立POWER接口的用途已核对。完整厂家PDF不复制入工程包，仅整理与接线有关的事实。

|连接|现用工程方法|
|---|---|
|视频|PYNQ-Z2 HDMI OUT→屏幕HDMI / HD IN，不接板卡HDMI IN|
|触摸|屏幕CTOUCH→PYNQ USB，使用支持数据传输的线，不是仅充电线|
|屏幕电源|说明书中CTOUCH兼具供电；需要独立供电时，POWER使用5V、2A能力的适配器|
|逻辑画布/视频输出|现用程序1280×720、BGR24、stride3840，每帧2764800字节|
|面板标称像素|说明书七寸规格1024×600，与输入视频分辨率分别记录|

本系统已使用七寸屏完成既有显示/触摸联调。说明书列出的面板像素不等于HDMI输入信号；现用输出为1280×720，不由面板像素推导完整EDID支持列表。屏幕精确品牌/型号、现用供电走线及USB VID/PID仍待补为复现记录。

说明书中的树莓派config.txt、树莓派镜像以及Windows注册表修复针对其他平台，不是本PYNQ工程部署步骤，不执行。触摸由原USB输入模块识别，须在ui4>启用touch on；根--precheck不会打开触摸设备，也不能替代实际触摸观察。

## 接线完成判据

22个不同数字端口与XDC相符、两CONVST共接、GND正确；供电和模式设置明确；HDMI OUT和USB数据均连接。实际运行时能够看到四页并正确触摸切换，错误不通过启动其他Reader/视频进程处理。文档和约束一致性不代替现场电平检查。
