# 数据获取与用途

冻结模型使用实板Feature/Adapter记录训练，示波器参考支持Run级标签。训练集2496帧、78Run、25谱系，全部属于TRAINING_ONLY；未将连续帧随机拆分成独立测试样本。生成器输出不能冒充实板训练记录。

复现原训练需要外部受控目录中的最终训练Manifest、对应数据、Run/参考关联及标签审核结果。原Manifest SHA256为8b0c5ccc7a84f10906f3e6d17542013d3800f16426bacbb4d1786f58272e9185。当前源码不附原始数据，长期获取位置仍待明确；没有这些输入只能运行工具和冻结模型，不能复现原训练。

EV26是另采12Run、384份保存输入，用于同设备新参数工况的候选比较。它已经用于选择模型，不能继续称为完全独立泛化测试，也不并入原TRAIN。

特征合同位于../preprocessing/feature_contract.json。v0.2.1管理器的标准导出与冻结训练Manifest字段不同，不能不经适配直接接入训练入口。限定标签policy不自动扩展到其他设备、工况或批次。
